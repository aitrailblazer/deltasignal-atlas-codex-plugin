Complete Setup, Funding, and Usage Instructions

1. Install the MCP Server

  1. Go to Smithery page
  2. Click "Connect" or choose your coding agent.
  3. Select your client: Codex, Claude Desktop, Cursor, Windsurf, OpenClaw, or any MCP-compatible agent.
  4. Copy the command or JSON configuration Smithery gives you.
  5. Restart the agent if it does not immediately discover the tools.
  6. Ask for DeltaSignal ATLAS-7 by name, or call the MCP tools directly.

2. Manual Install Commands

Codex CLI: smithery mcp add aitrailblazer/deltasignal-atlas-7 Codex plugin install: codex plugin install aitrailblazer/deltasignal-atlas-codex-plugin Codex Marketplace fallback: npx codex-marketplace add aitrailblazer/deltasignal-atlas-codex-plugin --plugin --project Claude Desktop / Cursor / Windsurf: Use the connection prompt from the Smithery page, or add the direct MCP config below. Advanced (direct MCP config): { "mcpServers": { "deltasignal-atlas-7": { "url": "https://api.aitrailblazer.net/mcp" } } }

3. Fund Usage After the Free Calls

  1. The first 5 calls are free for quick testing.
  2. Paid calls use USDC on Base through x402 micropayments.
  3. Use Coinbase Wallet, Coinbase Smart Wallet, or another Base-compatible wallet.
  4. Fund the wallet with a small amount of Base USDC. Start with $1-$5 for testing.
  5. Keep a small amount of ETH on Base for wallets that require gas. Some smart-wallet flows may sponsor gas; do not assume every wallet does.
  6. When your agent receives a 402 payment challenge, approve or let the x402-compatible client settle the request.

How to Add Funds (Beginner Guide)

After your free calls, usage is paid automatically with USDC on Base.

  1. Download Coinbase Wallet → coinbase.com/wallet
  2. Open app and create/import wallet
  3. Switch network to Base
  4. Buy USDC on Coinbase.com and send to your wallet on Base
  5. Done. Agent uses it automatically.
